# FashionRack 👗🛒
**A Lightweight POS & Inventory Management System**

FashionRack is a fully functional, frontend-only Point of Sale (POS) and Inventory Management web application designed specifically for retail clothing and fashion accessory stores. Built with a clean, fixed-layout UI, it provides a seamless experience for billing, managing products, and tracking sales history.

## 🌟 Key Features

* **🛒 POS Dashboard:** Browse products, add them to the cart, adjust quantities, and instantly calculate totals.
* **🧾 Print Receipts:** Automatically generates and prints professional, thermal-printer-friendly receipts using a hidden iframe method.
* **📦 Inventory Management (CRUD):** Add new products, update existing ones, edit images, and delete stock easily.
* **📜 Order History:** Automatically saves completed transactions. View past orders and detailed receipt summaries in a modal popup.
* **📄 Pagination & Search:** Easily navigate through large inventories with built-in pagination and live search/filter by category.
* **🖥️ Fixed Professional Layout:** Designed with a 100vh locked viewport (No page-level scrolling) for a true native POS software feel.
* **⚡ Single Page Application (SPA) Feel:** Uses vanilla JavaScript `fetch()` to load pages dynamically without refreshing the browser.

## 🛠️ Technologies Used

* **HTML5** - Semantic structure and component-based design.
* **CSS3** - Custom styling and layout locking.
* **JavaScript (ES6+)** - Core logic for cart, inventory arrays, and DOM manipulation.
* **Bootstrap 5.3** - Responsive grid system, modals, buttons, and UI components.
